fault-diagnosis-industrial-system

 AI-Based Fault Diagnosis in Industrial Systems

Project Overview
This project uses Machine Learning to detect faults in industrial systems based on sensor readings.

 Features
- Fault Detection
- Data Visualization
- Classification Report
- Confusion Matrix
- Predictive Maintenance

Technologies
- Python
- Google Colab
- Pandas
- Seaborn
- Matplotlib
- Scikit-learn

Algorithm
Random Forest Classifier

Output
The model predicts whether an industrial system is operating normally or has a fault.
